Wo steht der Sicherheitscode?

Für die Online-Abmeldung brauchen Sie zwei Arten von Codes. Wer sie freilegen kann, weist damit nach, dass er die Fahrzeugpapiere und Kennzeichen besitzt — sie ersetzen die Identifizierung per Personalausweis.

1. Zulassungsbescheinigung Teil I (Fahrzeugschein): Ein 7-stelliger Sicherheitscode, zunächst durch ein silbrig überdrucktes Feld verdeckt — ähnlich einem Rubbellos.

2. Stempelplaketten der Kennzeichen: Unter der Stempelplakette jedes Kennzeichens verbirgt sich ein 3-stelliger Code. Für die Abmeldung ist in der Regel der Code des hinteren Kennzeichens erforderlich.

So legen Sie die Codes frei

Fahrzeugschein freirubbeln: Rubbeln Sie das silbrige Feld auf der Zulassungsbescheinigung Teil I vorsichtig frei — am besten mit dem Fingernagel oder einer Münze. Darunter erscheint der 7-stellige Code.

Hintere Stempelplakette lösen: Lösen Sie die obere Schicht der Stempelplakette am hinteren Kennzeichen ab. Der 3-stellige Code wird darunter sichtbar.

Vorsichtig freilegen

Wird ein Code beim Freirubbeln beschädigt oder unleserlich, lässt sich die Abmeldung nicht mehr online durchführen. Arbeiten Sie langsam und mit wenig Druck.

Häufig gestellte Fragen

Wo finde ich den Sicherheitscode für die Online-Abmeldung?

Sie brauchen zwei Codes: den 7-stelligen Code auf der Zulassungsbescheinigung Teil I (unter einem verdeckten Feld) und den 3-stelligen Code unter der Stempelplakette des hinteren Kennzeichens.

Wie lege ich den Sicherheitscode frei?

Auf der Zulassungsbescheinigung Teil I rubbeln Sie das silbrig überdeckte Feld vorsichtig frei. An den Kennzeichen lösen Sie die obere Schicht der Stempelplakette ab. Arbeiten Sie vorsichtig, damit der Code lesbar bleibt.

Mein Sicherheitscode ist unlesbar — was nun?

Ist ein Code beim Freilegen beschädigt oder nicht mehr lesbar, ist die Online-Abmeldung nicht möglich. In diesem Fall ist die Abmeldung nur persönlich bei der Zulassungsstelle möglich.

Warum hat mein Fahrzeug keinen Sicherheitscode?

Sicherheitscodes gibt es erst für Fahrzeuge, die nach dem 01.01.2015 zugelassen wurden. Ältere Fahrzeuge tragen keine Codes und können nur vor Ort abgemeldet werden.
